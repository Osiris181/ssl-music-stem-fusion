# Banquet cleanup — 2026-10-28

The author authorized removing Banquet experiments and code from
`stem-fusion-music-classification/` after agreeing to an HT-Demucs-only
revision. This is the first cleanup step, not implementation of the new
matched controls or five-seed experiments.

## Removed from the active project

- Banquet separation and feature-extraction modules and CLI commands.
- Banquet separator configuration and Table 2 experiment matrix.
- Banquet manifest root/layout/suffix options and their dedicated source-root
  configuration class; mixture and multi-root HT-Demucs support remain.
- Banquet separation tests; shared MusicFM tests now use the HT-Demucs public
  entry point in `tests/unit/test_musicfm_features.py`.
- Three Banquet usage guides and obsolete references in directory READMEs.
- Table 2 reference-result CSV and experiment outputs, including checkpoints,
  predictions, metrics, logs, and provenance.
